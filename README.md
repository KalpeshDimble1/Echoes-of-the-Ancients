The project demonstrates object-oriented design, modularity, and extensibility through clearly defined classes:

Game.py – Controls overall gameplay, room navigation, combat, and quest progression.

Room.py – Manages location attributes (enemies, treasures, herbs, quests).

TextUI.py – Handles user interaction, dynamic descriptions, and command input.

Backpack.py – Manages player inventory and stamina restoration.

Player.py – Tracks player stats, experience, and level progression.

Players can move between locations, collect treasures and herbs, engage in battles, complete quests, and manage resources to survive and progress.

🧭 Features

8 unique, connected locations (Forest, Village, Mountain, Cave, Ancient Ruins, Farm, Mystic Lake, Sky Fortress).

Turn-based combat and stamina restoration.

Quest and treasure mechanics with key-based progression.

Dynamic world updates (room resets, regenerating items/enemies).

Simple Python execution: no external dependencies required.

🧩 Learning Goals
This project reinforces:

Modular OOP design in Python.

Game logic and event-driven programming.

Handling user input and text-based state management.
